## Поинты для отображения групп

<i>Выдает все группы в виде отсортированного списка</i>

Пример вывода:

```json
[
    "1 БПЛА",
    "10 МРТ",
    "13 ДОУ",
    "2 БПЛА",
    "2 РЭУ",
    "20 МОНТ",
    "21 МОНТ",
    "35 ЭМЕХ",
    "36 ЭМЕХ",
    "37 ЭМЕХ",
    "4 ИКС",
    "5 ИКС",
    "6 ИКС",
    "7 ИКС",
    "7 МРТ",
    "8 ИКС",
    "8 МРТ",

    ...
]
```

---

### `GET` `/api/groups/departments`

<i>Выдает все группы в формате разделения на отделения</i>

Пример вывода:

```json
{
    "oit": [
        "ИБ1-11",
        "ИБ1-21",
        "ИБ1-31",

        ...
    ],
    "oar": [
        "АР1-11",
        "АР1-13",
        "АР1-21",
        "АР1-23",
        "АР1-31",

        ...
    ]
}
```

---

### `GET` `/api/groups/find-department?group=`

<i>Ищет отделение, на основе группы, переданной в параметры</i>

Пример вывода:

```text
oit
```

---

### `GET` `/api/groups/department-names`

<i>Даёт имена всех отделений (их также можно посмотреть в файле `groups.cfg`)</i>

Пример вывода:

```json
[
    "oar",
    "oeis",
    "oit",
    "ort",
    "out",
    "so"
]
```

## Расписание


### `GET` `/api/schedule`

<i>Выдает расписание на сегодня для всех групп</i>

Параметры `group` и `date` работают как фильтр:

- `group` — фильтр по учебной группе;
- `date` — фильтр по дате.

Пример запроса с фильтрами:

```text
/api/schedule?group=ЗМ1-11&date=2026-09-17
```

Пример вывода без фильтров:
```json
{
    "ЗМ1-11": {
        "group": "ЗМ1-11",
        "day": "Четверг",
        "weekType": "DENOMINATOR",
        "date": "2026-09-17",
        "pairs": [
            {
                "pairNumber": 0,
                "numerator": {
                    "empty": false,
                    "rooms": [
                        "А201"
                    ],
                    "subjects": [
                        "Основы шахматной игры"
                    ],
                    "teachers": [
                        "Кургузова М.С."
                    ]

                    ...
                }
            }

            ...
        ]
    }

    ...
}

```

### `GET` `/api/schedule/current-weektype`

<i>Выдает текущий тип недели</i>

Пример вывода:

```json
{
    "label": "Знаменатель",
    "weekType": "DENOMINATOR"
}
```
weekType может принимать значения:

- `DENOMINATOR` — знаменатель;
- `NUMERATOR` — числитель.


> Также, когда на данную дату нет данных, выводится: 
```json 
{
  "error": "Снапшот на дату 2026-09-16 ещё не посчитан"
}
```
> Это относится ко всем поинтам в этом разделе
