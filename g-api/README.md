# GradInator API

Backend REST API для проекта **GradInator**.

G-API отвечает за работу с расписанием Ярославского градостроительного колледжа:
- получение расписания групп;
- поиск доступных групп, преподавателей, кабинетов и предметов;
- работу с системными данными;
- мониторинг состояния приложения.

Проект построен на **Spring Boot**.

---

## Основные возможности

### Schedule

Получение расписания:

- конкретная группа и дата;
- расписание на сегодня/завтра/вчера;
- расписание недели;
- текущий тип недели.

### Metadata

Получение справочной информации:

- список групп;
- список преподавателей;
- список предметов;
- список кабинетов.
